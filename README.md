# Excavation

**Excavation** adds a simple quality-of-life enchantment for builders, miners, and anyone tired of clearing space one block at a time.

With the **Excavation** enchantment, pickaxes and shovels can mine a **3x3x3 area** when you break a block. It is designed to feel like a natural Minecraft enchantment rather than an overpowered creative tool.

## Features

* Adds the new enchantment **Excavation I**
* Works on **pickaxes** and **shovels**
* Mines a **3x3x3 area** around the block you break
* Appears in the **enchanting table**
* Can show up as a normal, common enchantment
* Respects normal Minecraft block-breaking behavior
* Works with **Silk Touch**
* Should work with **Fortune** anywhere Minecraft normally applies Fortune drops
* Only breaks blocks your held tool can properly mine
* Skips air and unbreakable blocks

## How It Works

Enchant a pickaxe or shovel with **Excavation**, then mine as normal. When you break a valid block, nearby valid blocks in a 3x3x3 cube are also broken using Minecraft’s normal block-breaking logic.

That means the mod does not simply delete blocks. Drops, tool behavior, and enchantments are handled through the normal Minecraft systems.

## Balance

Excavation is intended as a common utility enchantment. It can appear in low-level enchanting table rolls, making it useful early without needing to wait for a perfect max-level setup.

There is currently only one level:

**Excavation I**

## Requirements

* Minecraft Java Edition **26.3**
* Fabric Loader
* Fabric API
* Java 25

## Notes

This mod is meant for faster building, mining, terraforming, and clearing. It is especially useful when digging rooms, tunnels, basements, farms, or large build spaces.
